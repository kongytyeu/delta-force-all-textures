# Delta Force All Textures

三角洲行动相关的公开图标与贴图资源整理包，面向攻略作者、Wiki 维护者、数据分析工具、图鉴、数据库和其他内容创作者。

本仓库收录了约 **11,574 张 PNG 素材**，按游戏物品分类整理。文件名使用物品中文名，目录结构保留主分类与二级分类，便于人工浏览，也便于程序按路径检索。

## 快速使用

### 浏览素材

下载仓库后，直接用浏览器打开 [`_预览.html`](./_预览.html)，可以按分类浏览并搜索物品名称。

预览页依赖相对路径读取图片，请保持 `_预览.html` 与各分类目录处于同一层级。

### 程序检索

[`_物品索引.xlsx`](./_物品索引.xlsx) 提供物品名称、分类和文件路径的对应关系，适合用于制作：

- 物品图鉴和 Wiki
- 武器、配件和装备数据库
- 搜打撤物资查询工具
- 攻略页面和内容管理工具
- 数据可视化与统计脚本

[`_未收录清单.xlsx`](./_未收录清单.xlsx) 记录目前没有独立二维图标或尚未整理的条目。

## 文件与图片说明

- 图片主要为 RGBA 透明 PNG，可直接叠加到网页、图鉴或其他创作背景上。
- 图片尺寸按照游戏内资源原始尺寸保留，不保证统一大小；批量使用时请按场景自行缩放。
- 同一张图可能被多个物品共用，并以不同文件名分别保存，这是正常的目录索引结果。
- 基础武器的白色剪影是游戏内物品图标表现；带彩色立绘的内容通常属于外观或皮肤资源。
- 少数物品没有独立二维图标，因此不会出现在本资源包中。
